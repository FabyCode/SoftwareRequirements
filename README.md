# Spl-it

Spl-it is a shared case-study project for the **Software Requirements Engineering** course at ITESO.

## Project Overview

Spl-it is a collaborative web application and Software as a Service (SaaS) platform that makes sharing expenses easy for groups by tracking purchases, calculating each person's share, and showing exactly who owes who.

Examples of group scenarios may include:

- Roommates
- Travelers
- Couples
- Families
- Student teams
- Event organizers
- Groups of friends

## Purpose

The project explores how a digital platform could:

- Eliminate calculation inaccuracies and uneven splits.
- Reduce social and interpersonal friction.
- Decrease administrative overhead for primary payers.
- Automate expense logging and balance calculations.
- Provide immediate, transparent balance visibility.
- Calculate optimal debt-settlement paths to minimize total transactions.
